# 页面与权限

## 学生端

| 路由 | 作用 |
|---|---|
| `#/` | 进入任务：身份、目标和开始按钮 |
| `#/map` | 任务地图与手册日程对照 |
| `#/train` | 岩层、化石、时间排序、观察/解释分类 |
| `#/sites` | 西屯与珠江源入口 |
| `#/xitun` | 古环境证据选择 |
| `#/zhujiang` | 材料—方法—结论配对 |
| `#/compare` | 对照滑杆、热点、比较表、目的论改写 |
| `#/lab` | CT 层级、数字观察记录、AI 引用判断 |
| `#/kit` | 安全、任务清单、观察卡 |
| `#/work` | 海报草稿与每日反思 |
| `#/sources` | 来源与术语 |
| `#/privacy` | 本地保存与隐私边界 |

## 教师端（预留，未启用）

`#/teacher` 只说明后续能力：班级、完成状态、现场准入、临时通知、海报审核、素材授权。当前没有账号，页面不会显示审核结果。

未配置身份系统。所有访问者看到同一学生界面。接入 SSO 后才区分学生、教师、导师、管理员，见 `docs/sso.md`。
