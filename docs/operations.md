# 后续运营

- 改任务句子：编辑 `js/pages.js` 与 `js/content.js`，不要把未核实的数字、排名或人员写进去。
- 改行程：先更新 `docs/programme-notes.md`。只有组织方确认、且适合学生看到的内容才进任务地图。
- 换图：新文件放进 `public/assets/media/`，在 `FIGURES` 写清类型（原始 / 处理 / 复原）、图注、页码和 alt，并在 `docs/asset-inventory.md` 补一行。授权未确认的图不要放到公开域名。
- 撤回公开内容：从 `FIGURES` 或页面移除对应块，并删除已部署副本。本地 `localStorage` 不会自动从学生浏览器消失。
- 审核作品：第一期没有提交接口。学生导出的是本机文本，教师不能在此站看到草稿。
- 学生作品、照片、定位和姓名默认不公开。
